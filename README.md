# 🧮 Discrete Structures CLI Toolkit

> A lightweight, object-oriented C++ command-line interface (CLI) for executing mathematical set operations and validating relational properties.

## 🔬 Project Overview

This toolkit bridges the gap between theoretical discrete mathematics and applied software engineering. It provides an interactive terminal environment to compute complex set theories and test mathematical relations instantly, serving as an efficient calculator for discrete logic.

## ⚡ Core Modules & Features

### 1. Set Theory Engine
Input elements to automatically process and compute core set logic:
*   **Union (`A ∪ B`) & Intersection (`A ∩ B`)**
*   **Absolute Difference (`A - B`)**
*   **Cartesian Product (`A × B`)**
*   **Subset & Equality Checking**
*   **Universal Complement Validation**

### 2. Relational Logic Processor
Feed ordered pairs into the system to evaluate mathematical properties:
*   **Property Validation:** Tests for Reflexive, Symmetric, and Antisymmetric behaviors.
*   **Function Verification:** Confirms if a mapped relation qualifies as a valid mathematical function.
*   **Data Extraction:** Computes and displays the Inverse Relation, Domain, and Range.

## 🏗️ Technical Architecture

*   **Language:** C++ (Standard Template Library)
*   **Paradigm:** Object-Oriented Programming (OOP)
*   **Structure:** Utilizes class inheritance (Base `Set` class and Derived `Relation` class) for clean data encapsulation.
*   **Interface:** Menu-driven, continuous-loop terminal UI.
